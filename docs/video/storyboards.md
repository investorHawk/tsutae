# デモ動画の構成 3 案（150 秒、Remotion）

2026-11-04 Claude 作成。実装は `video/`（Remotion）。3 案は同じ部品を共有し、Studio で切り替えて比べられる。画面の録画は後で撮り、`video/public/footage/<id>.mp4` に置くと差し替わる（置くまでは「何を・何秒撮るか」の枠が出る）。

共通の約束:
- 1920×1080、30 fps、**ちょうど 150 秒（4500 フレーム）**。各案の場面の秒数の合計はテストで検査する
- 冒頭 15 秒以内に「誰の・どんな課題を・どう解決するか」を言い切る（審査基準デモ 25%）
- 2 つの利点を必ず言葉にする: **医師は短時間で必要な情報が十分に得られる**／**患者は言い忘れなく、日々思っていたことを医師に伝えられる**
- 一本の糸: 患者が Day7 に書いた「おとといの夜から口内炎がいたい」が、レポートの Day5「口腔粘膜炎」に原文の引用つきで載るところまで追う（見せて伝える）
- 「症例は全て合成（架空）」の札を 150 秒ずっと右上に出す（医師画面にはこの注記が無いため動画側で補う）
- 字幕は 2 行以内・1 行 25 字前後・40 px 以上。字幕の文は 1 案あたり 650 字前後（4〜4.5 字/秒）
- `docs/demo-script.md`（4 分の台本）から 90 秒短い。D5（変換ログの画面）は動画では見せず、仕組みはアニメーションで描く。印刷・未処理・印刷済みは 1 拍ずつ

## 推奨: 案 B「3 分が 30 秒になる」

理由: 先生が挙げた 2 つの利点（医師の時間・患者の言い忘れ）に最も直結し、受賞作の型「使う前後の差を一つの数字で見せる」そのもの。冒頭 8 秒で「3:00 → 0:30」が出るので、前提知識のない審査員にも価値が伝わる。案 A は物語として引き込みやすく、案 C は「Claude の活用 25%」と安全設計を前面に出す。迷うなら B、技術寄りの審査員を強く意識するなら C。

## 字幕の文

音声のナレーションは入れない。表の「字幕の文」の列は構成データの `narration` で、各案の全文と時刻は `docs/video/narration-<a|b|c>.md`（`npm run docs` で構成データから生成）。

## 使い方

```bash
cd video && npm install
npm run studio            # ブラウザで 3 案を切り替えて確認（DemoA / DemoB / DemoC）
npm run render -- DemoB out/demo-b.mp4   # 書き出し（150 秒。数分かかる）
npm run still -- DemoB out/b-60s.png --frame=1800   # 60 秒時点の静止画
npm test                  # 各案の合計が 150 秒であることなど
```

Claude Code のサンドボックス内ではブラウザが起動できないので、studio と render は先生が `!` で実行する。

## 備考

- Remotion のライセンス: 個人・3 人以下のチームは無償（会社での利用は要確認）。本作はソロ
- フォントはシステムの Hiragino Sans（無ければ Noto Sans JP）。描画時にネットワークへ出ない
- 色: 紙の白（#f6f4ef）、墨（#1a1a1a）、患者画面の紺（#0b4a9c）と紫（#4b2a7b）
