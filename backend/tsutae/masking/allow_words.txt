# 伏せ字の許可語（1行1語。# で始まる行と空行は無視）
# 二次検出 unknown_before_honorific / before_facility で、敬称・施設名の直前の語が
# 「この語で終わる」なら伏せ字漏れとみなさない。敬称つきの形と語だけの形の両方を書ける。
# 一次置換では、病院名の前に付いた時を表す語（「今日病院へ」の「今日」）を残すのに使う。
# 名前の末尾になりやすい1字（夫・子・美・郎 など）は書かない（「和夫さん」を通してしまうため）。
# この語で終わっても、その前に別の語が切れ目なく続くなら許可しない（words.py の is_allowed）:
#   「磯鷲看護師さん」「林看護師さん」「守屋さん」（1字の語の前には何も残せない）、
#   「さとうさん」（ひらがなの語の前のひらがなは、許可語・助詞・活用の切れ目で説明できること）。
