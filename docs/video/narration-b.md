## 字幕の全文

私は 25 年間、消化器外科医としてがん治療を行ってきました。診断から手術、化学療法、緩和医療をしてきました。がん化学療法中の副作用を、短時間で、抜けを減らして把握する。つたえ。
抗がん剤の治療中、症状は 1 日 1 日変わります。つらい日も、診察の日には回復し、忘れていることもあります。短い診察で、2 分かけて聞き取っても、抜けが残ります。
レジメン別のノートは複数出ていますが、書式はまちまち。患者さんは書き方を学び、医師は読むのに時間がかかります。そこで、患者さんにも医師にも使いやすいアプリにしました。
つたえがあると、診察の前に A4 一枚が机にあります。先頭に要確認。医師は 20 秒で、何を聞くべきかが決まります。
外来化学療法の患者さんは毎日スマホで、3 択と自由記載を記録します。つらい日はボタン 1 つ。抗がん剤が変わっても、入力の形は同じ。決めた時刻にお知らせが届き、書き忘れと言い忘れが減ります。
受診日は、受付番号を入れて送るだけ。患者さんの画面に AI の文は出ません。記録はスマホに保存。サーバーへ送るのは受診のときだけで、印刷が済むと消します。
人名などを伏せ字にした自由記載を、Claude Agent SDK が日付と症状の用語にそろえ、原文の引用つきの A4 一枚にします。
経過表で、前のコースの同じ日と比べられます。自由記載も症状ごとに日付順で読め、元の文も引用で載ります。「おとといの夜から口内炎がいたい」は、Day5 の口内炎と記載されます。
新しいレジメンも、医師がチャットから文で伝えるだけ。Claude Agent SDK が指示どおりに設定します。入れた値は、医師が確かめてから採用します。
電子カルテは、セキュリティのために変えるハードルが高い。そこで、あえて今、紙にしました。どの病院でも、すぐに導入できます。
AI は、副作用の重さの判定や助言をしません。判断は医師が行います。
私の実感では、聞き取り 2 分が、20 秒に。その分を、判断や対話に使えます。明日から、自分の患者さん一人一人に渡して使いたい。そういうソフトウェアができました。なお、症例は全て合成です。ご視聴ありがとうございました。
